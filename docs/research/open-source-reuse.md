# Open-source reuse research for Atrium

Date: 2026-10-24. Author: research sub-agent (read-only task; this is the only file created).

## How to read this

- **Licence policy (owner decision, 2026-10-24):** Atrium may be published and licensed **AGPL-3.0**. So AGPL and GPL code is a **copy and adapt candidate**, not "learn only". See section 4 for what that costs and which licences still cannot be combined.
- **Verification:** every licence below was read from the project's own LICENSE file or its npm registry entry on 2026-10-24. Where GitHub's detector said "NOASSERTION" (BlockNote, Yjs, formulajs, rrule, MCP SDK, HyperFormula, Pragmatic DnD, Focalboard, Planka, NocoDB, Baserow, Teable, Twenty, Rowy, AFFiNE, n8n, Activepieces, tldraw, Outline) I opened the LICENSE text. Stars and "last release" come from the GitHub API and npm on the same date.
- **Bundle sizes** are Bundlephobia minified+gzip for the whole package entry point, so tree-shaking can shrink them. Not measured: Pragmatic DnD (Atlassian quotes about 5 kB for the core), `@lexical/react`, the MCP SDK.
- **Effort figures** are my estimates, not measurements.
- **Not verified this session** (marked "unverified" where used): AG Grid Enterprise feature split, react-big-calendar's drag-and-drop addon being free, Schedule-X's premium list beyond its docs page (pricing page returned HTTP 502), FullCalendar v7 theming, MCP SDK OAuth helpers.
- Stack facts that shape everything: Atrium is React 19.3, `@vibe/core` 4.5.38 (MIT; npm field and `packages/core/LICENSE` say MIT, the repo has no root LICENSE so GitHub shows none), Firebase JS SDK **13.1.0**, TanStack Virtual and dnd-kit 6.3.1 already installed, tokens-only styling enforced by Stylelint.

## 4. Licence risks

### 4.1 What Atrium becoming AGPL-3.0 allows

| Incoming licence               | Can go into an AGPL-3.0 app?                                                              | Examples here                                                                             |
| ------------------------------ | ----------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| MIT, BSD, ISC, CC0, Apache-2.0 | Yes. Apache-2.0 is compatible with GPLv3/AGPLv3 (not GPLv2)                               | Vibe, TanStack, FullCalendar, Recharts, Tiptap, Yjs, MCP SDK v2, react-aria, Firebase SDK |
| MPL-2.0                        | Yes (secondary-licence clause), unless a file says "Incompatible With Secondary Licenses" | BlockNote core, `ical.js`                                                                 |
| GPL-3.0-only                   | Yes (GPLv3 section 13 lets it combine with AGPLv3)                                        | HyperFormula (under its GPL option), BlockNote XL (GPL option), OpenProject               |
| AGPL-3.0                       | Yes. Pick **AGPL-3.0-only** for Atrium unless every lifted file says "or later"           | Plane, Focalboard, Docmost, Teable apps, Twenty, Vikunja, AppFlowy                        |

### 4.2 Flags

**Commercial or dual-licence (a paid licence is needed to use the paid part):**

- **Bryntum Gantt**: commercial. The npm listing says MIT, but the package is a placeholder.
- **DHTMLX Gantt**: Community edition is MIT now (LICENSE.md and npm); Pro features are paid.
- **SVAR React Gantt PRO**: auto-scheduling, critical path, baselines, grouping, MS Project import/export.
- **FullCalendar Premium**: `timeline`, `resource-timeline`, vertical resource views; from $480 for 1-10 developers (pricing page).
- **Schedule-X premium**: drag-and-drop and resize ship as `@sx-premium/*` (unverified beyond the docs page).
- **HyperFormula**: GPL-3.0 **or** proprietary, selected by licence key. The GPL option is now usable, but the library is a poor fit.
- **BlockNote XL packages** (`@blocknote/xl-*`): `GPL-3.0 OR PROPRIETARY`.
- **Tiptap Platform**: cloud collaboration, comments, AI, document history and DOCX/PDF import-export are paid. The MIT editor and extensions are free.
- **SurveyJS Creator**: commercial. **Mapbox GL** and **AG Grid Enterprise**: commercial (AG Grid split unverified).

**Licence-incompatible with an AGPL-3.0 Atrium:**

- **Huly** (EPL-2.0, no GPL secondary-licence designation).
- **Planka** (Fair Use licence with extra restrictions).
- **NocoDB** and **n8n** (Sustainable Use Licence), **Outline** (BSL 1.1), **tldraw** (custom licence).
- **react-leaflet** (Hippocratic-2.1).

**Commercial files inside otherwise-copyable repos. Check before every copy:**

- Twenty: files starting `/* @license Enterprise */`.
- Docmost: `apps/client/src/ee`, `apps/server/src/ee`, `packages/ee`.
- Baserow: `premium/` and `enterprise/`.
- Planka: `.pe.` files.
- n8n: `.ee.` files.
- AFFiNE: `packages/backend` has its own licence.

**Trademark and brand:**

- Teable: AGPL section 7(e) additional term on its brand assets.
- Mattermost: Focalboard's trademark rules.
- Planka: name and logo use is limited.
- monday: never use its name, logo or marketing art (already an AGPL-independent rule in `AGENTS.md`).

**Other:**

- **Stale peers.** Glide Data Grid (React 18), `@emoji-mart/react` (React 18), Tremor (React 18), `y-fire` and `@gmcfall/yjs-firestore-provider` (firebase 9/10). The licence is fine, but they will not install cleanly with React 19 or firebase 13.
- **MCP SDK** is mid-transition from MIT to Apache-2.0. Either way it is permissive. Keep copyright notices for both.
- **Provenance.** Every lifted file needs a header comment or `docs/third-party/` entry: source repo, path, commit SHA, licence. Without it, AGPL compliance and later upgrades are guesswork.

### 4.3 What adopting AGPL-3.0 means for Atrium

1. **Add a `LICENSE` file** with the AGPL-3.0 text at the repo root, set `"license": "AGPL-3.0-only"` in each `package.json`, and consider SPDX headers on new files.
2. **Keep upstream copyright notices.** Lifted files keep their original header. Add a `NOTICE` or `THIRD_PARTY_NOTICES.md` listing each source, licence and path. Generate the npm part from `pnpm licenses list --json` in CI so new dependencies cannot slip in unseen. The production bundle also needs a notices page, since Vite strips comments.
3. **Offer the source to users.** Atrium is a network service and will be a modified AGPL work, so section 13 applies: show a visible "Source code" link (footer or About) that points to the repo at the deployed commit or tag.
4. **No secrets in the repo, including history.** Before flipping public:
   - Scan the full git history and rotate anything found.
   - Confirm no service-account keys, `.env.local`, emulator data, or real family emails in seeds and fixtures.
   - The Firebase web config is public by design (`AGENTS.md`).
   - Check that Actions logs and PR comments hold nothing private.
5. **Private reference screenshots stay out.** `docs/reference/monday/` is gitignored today. Verify that it never entered history (`git log --all -- docs/reference/monday`) and decide whether `docs/reference/monday-ui-reference.md` should be published. Visual-regression baselines show only Atrium screens and are fine.
6. **Forks must publish too.** Anyone who forks and serves a modified Atrium has the same obligation. Atrium's own new code stays the owner's copyright, but lifted AGPL code cannot be re-licensed later.
7. **Not legal advice.** This is an engineering reading of the licence texts. A short review before going public is cheap.
