# 2026-11-18 Claude: P8 PR 5 (OpenAPI, parity test, /developers)

Branch `claude/p8-docs`, from `origin/main` after the API write routes and the outgoing webhooks backend.

## What was done

- `functions/src/api/openapi.ts`: OpenAPI 3.1 built in code, no new dependency. One `OPERATIONS` entry per
  route, keyed `'METHOD /path/{id}'`. Request bodies come from the write routes' own zod schemas through
  `z.toJSONSchema` (`createBody`, `patchBody`, `subitemsBody`, `updateBody` are now exported from
  `routes/writes.ts`), so they cannot drift. Components: `bearerAuth` (scopes read/write), the `Error`
  schema with all codes, shared error responses, the `Idempotency-Key` header parameter (on every POST).
- `functions/src/api/routes/openapi.ts` + one import and one `app.get(...)` line in `app.ts`: the document is
  served at `GET /api/v1/openapi.json` before the authenticated router (no token), with
  `Cache-Control: public, max-age=3600`. It sits behind the kill switch like the rest.
- `scripts/api-parity.test.mjs`: routes folder, OpenAPI table and the /developers route table must list
  the same routes; the limits, the idempotency TTL and the error codes on the page must equal the source.
  It reads the TypeScript as text with small regexes (no loader needed); `openapi.test.ts` also compares
  the built document with the real route objects.
- `/developers` (public, outside `RequireAuth`): `pages/developers/` with `developers-content.ts`
  (typed facts), the page and its CSS module. Linked from Settings > Account > API tokens and the About dialog.
- Visual: `developers` added to `tests/visual/src/screens.spec.ts` (light and dark) and to
  `mobile-screens.ts` (also in `BASELINE_SCREENS`), like `privacy`.

## Gotchas

- The API sends only `Retry-After` on 429; there are no `X-RateLimit-*` headers, so none are documented.
- The limits and error codes on the page are duplicated constants, pinned by the parity test.
- Code blocks use `--atrium-doc-code-font` (the only monospace token); Stylelint bans a literal `monospace`.
